# Usuários

React + Vite + TypeScript consumindo a API JSONPlaceholder.

```bash
npm install
npm run dev      # desenvolvimento
npm test         # testes (Jest + React Testing Library)
npm run build    # checagem de tipos + build de produção
```

**Recursos:** listagem, busca por nome (ignora acentos), visualização em grade/lista,
modal de detalhes (`<dialog>` nativo), estados de carregamento/erro com retentativa,
tema claro/escuro (respeita `prefers-color-scheme` e persiste a escolha), CSS Modules.
